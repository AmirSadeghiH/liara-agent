Transport اصلی stdio است. در این حالت stdout مخصوص پروتکل MCP است و همه لاگ‌ها به stderr می‌روند. اجرای سرور به توکن لیارا یا LLM وابسته نیست؛ در حالت DEMO همه ابزارهای خواندنی از آداپتور شبیه‌ساز پاسخ می‌دهند.

{{ icon('user', 16) }} Claude Code

stdio
روش اول: افزودن سرور با CLI (از ریشه پروژه اجرا شود).
claude mcp add liarapilot -- python -m app.mcp.server
روش دوم: فایل .mcp.json در ریشه پروژه.
{
  "mcpServers": {
    "liarapilot": {
      "command": "python",
      "args": ["-m", "app.mcp.server"],
      "env": { "DEMO_MODE": "true" }
    }
  }
}
سپس با claude mcp list اتصال را بررسی کنید.

{{ icon('mcp', 16) }} Codex

stdio
فایل ~/.codex/config.toml:
[mcp_servers.liarapilot]
command = "python"
args = ["-m", "app.mcp.server"]
env = { DEMO_MODE = "true" }
یا افزودن سریع با CLI:
codex mcp add liarapilot -- python -m app.mcp.server
در ویندوز اگر python در PATH نیست، مسیر کامل .venv\Scripts\python.exe را بگذارید. صحت پرچم‌ها را با codex mcp add --help بررسی کنید.
